# Upstream

This repository is the hackathon submission copy of
[`agapemiteu/corri`](https://github.com/agapemiteu/corri). It carries none of
that repository's commit history, by design: the Classroom history starts at the
GitHub Classroom initial commit.

**Base commit:** `3abbb47` on `main`, "merge: resolve Michael's snooze and
service updates".

Application code is upstream's. The differences below exist so the project can
be graded, run by someone who has not used a terminal much, and deployed. Keep
this list short. Anything not needed for those three reasons belongs upstream,
not here.

## Re-syncing with upstream

```bash
git remote add upstream https://github.com/agapemiteu/corri.git   # once
git fetch upstream main
```

Do not merge. Upstream history must not enter this repository. Copy the files
that changed instead:

```bash
git diff --stat HEAD upstream/main -- apps packages website
git checkout upstream/main -- <path>
```

Then re-apply anything from the Changed table that the copy overwrote, and run
`pnpm check` before committing.

To see the current divergence at any time:

```bash
git diff --stat HEAD upstream/main
```
